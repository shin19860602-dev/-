# 月別の日別売上・経費Excel出力

売上画面の先頭に出力月とダウンロードボタンを追加。選択店舗の1日〜月末を出力。
列：日付、現金売上（技術）、クレジット売上（技術）、ポイント、商品現金売上、商品クレジット売上、経費。
売上のない日は数値0。最下段はSUM数式と計算済み値による月合計。28/29/30/31日に対応。
登録済みの技術金額からポイントを再控除しない。技術と商品の支払方法は既存のpaymentMethodを共用。
経費は登録済み全カテゴリの金額を日別合算。現金経費だけの判別や売上からの控除は行わない。
支払方法未登録の売上は現金扱いにせず、確認シートへ金額を出しメインシートに注意表示。

API /api/reports/monthly-sales?month=YYYY-MM&store=店舗slug。
現在のDB上の役割・有効状態・店舗所属で認可し、スタッフは自店舗、オーナーは選択サロンか全サロン。
不明な店舗指定で全店舗へ広げない。古着は対象外。顧客名・電話番号・スタッフ名は取得・出力しない。
売上と経費をRepeatableReadトランザクションで読み取り、DBへの書き込みはない。
レスポンスはprivate/no-store。ExcelJS 4.4.0、UUIDは11.1.1へ固定。

検証：新規8件＋既存14件の22テスト成功、型チェック成功。
Excel再読込で列順・数値・ポイント・経費・SUM・不明支払確認シートを検証。
EdgeのDB非接続フィクスチャで320/375/1280px、月・店舗パラメータ、ファイル名、403表示と再操作を確認。
実本番データでの出力と本番デプロイは未実施。DB移行不要。

依存監査で既存Next.js等の指摘も見つかったが、本機能の作業で無関係な基盤更新は実施していない。
ExcelJS由来のuuid指摘には修正版への限定overrideを追加。基盤更新は別途評価が必要。
