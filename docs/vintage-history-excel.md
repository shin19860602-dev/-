# 古着部門の過去月表示とExcel出力

対象：古着倉庫KUJEKUJE。売上履歴とダッシュボードでmonth=YYYY-MMを選択できる。
月未指定は日本時間の今月。不正・複数指定の年月はエラー表示とし、全期間や今月へ黙って広げない。
月切替は表示中のタブを維持し、タブ切替でもmonthを引き継ぐ。新しい売上の登録日とは別の表示条件。
ダッシュボードの月合計・現金/クレジット・分類別・ブランド別は全て同じ選択月のデータを使用。
履歴の表示日付と編集用日付を日本時間に揃える。保存データの書き換えはしない。

/api/reports/vintage-sales?month=YYYY-MMで日別Excelを出力。
列：日付、現金売上、クレジット売上。1日〜月末、売上なしは数値0、月合計はSUMと計算済み値。
28/29/30/31日に対応。支払方法未登録の売上は現金扱いせず、注意文と確認用別シートへ出力。
オーナーか古着部門の自店舗STAFF/MANAGERだけ利用可能。出力時のDB上の現行権限で確認する。
任意のstoreIdをクエリから受け取らず、サーバーで古着店舗と照合。顧客・スタッフ名・メモはExcelに出さない。
private/no-store。DB移行・seed・売上削除や更新・追加依存ライブラリはなし。

検証：
- 古着7件を含む計32テスト、型チェック成功。
- 生成Excel再読込で列順・全日付・数値・月合計・支払方法不明の確認シートを検証。
- 実ページ処理をモックDBで呼び、過去月・日本時間境界・不正月時に売上を問い合わせないことを確認。
- 実ブラウザのフィクスチャで320/375/1280px、月変更、タブへの引き継ぎ、ダウンロード年月/ファイル名、403後の再操作を確認。

本番反映はユーザーの明示承認後。本番実データのダウンロードは未確認。
